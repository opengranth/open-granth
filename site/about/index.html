About Open Granth

What is this?

Open Granth is a markdown-first presentation of the complete Sri Guru Granth Sahib Ji: all 1,430 angs with Gurmukhi and romanized transliteration.

On that foundation, Open Granth provides a browsable website, search, and verification tooling for AI clients and human readers alike.

Open Granth is offered as seva. The site has no ads, accounts, analytics cookies, cross-site tracking, or commercial features. Privacy-preserving aggregate traffic measurements from Cloudflare help show how the site is used. Open Granth never profiles visitors or collects search or verification text. Gurbani remains freely accessible to anyone with a web browser.

Project scope

Open Granth version 1 presents all 1,430 angs of Sri Guru Granth Sahib Ji. It does not currently include Jaap Sahib, Tav-Prasad Savaiye, or Benti Chaupai. These bani hold an important place in Sikh practice. Their absence reflects only the current scope of Open Granth and carries no judgment about their significance.

Why build this?

I started using AI tools regularly, for both personal and professional work. Naturally, I began asking AI about Gurbani. What does Guru Nanak Dev Ji say about ego? Which shabads speak to grief?

The answers I received sounded confident. They also contained verses that don't exist.

AI models can hallucinate. For most topics, a wrong answer is an inconvenience. For sacred scripture, it's something else entirely. I was reading fabricated Gurbani without realizing it. I later learned that other Sikhs had encountered the same problem.

Accuracy matters here in a way it doesn't for most things. Gurbani is Guru. Misquoting it is harmful.

Open Granth was created to address this. Every verse is stored as plain text, readable by humans and machines alike. The project includes an MCP server that lets AI tools retrieve Gurbani from the released source files with ang and line citations rather than generate passages from model memory.

Open Granth is for anyone who wants to read Gurbani and seek Naam using the tools of today. Search can help locate a passage. The verifier checks quotations against the released source.

Sources and provenance

Gurmukhi text and metadata: derived from the Shabad OS database.

English translation: imported from the DSSK translation asset in the Shabad OS database, attributed there to Dr. Sant S. Khalsa. Included as a study aid.

Romanized transliteration: mechanically generated by Open Granth as an approximate companion to the Gurmukhi. It is not an authoritative pronunciation guide. Within Open Granth, the Gurmukhi is the source layer; the Roman and English layers are reading aids.

Built by Open Granth: the Markdown corpus format covering all 1,430 angs, the static website and search, the citation-first verification system, and the seven-tool MCP server.

Open Granth is an independent project. It is not affiliated with, endorsed by, or sponsored by Shabad OS or any Gurdwara, Jatha, Takht, or Sikh institution.

Provenance is documented so the project’s sources and transformations can be audited. See the NOTICE file, the transliteration documentation, and the detailed provenance record for complete attribution.

English translation

The English layer is an imported study aid, not Open Granth's own interpretation. Open Granth will not present AI-generated interpretation as authoritative Gurbani.

Open Granth does not claim religious, scholarly, or interpretive authority. If a rights holder believes a translation passage should be corrected, reattributed, or removed, the project maintains a public takedown process.

Accuracy

This site renders its source text as faithfully as possible. If you find errors in text or transliteration, open an issue on Open Granth with the ang and line numbers.
