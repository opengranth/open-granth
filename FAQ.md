# FAQ

## What is Open Granth?

Open Granth is a markdown-first presentation of the complete Sri Guru Granth Sahib Ji: all 1,430 angs stored as plain text files, with a browsable website, search, a citation-first verification tool, and an MCP server for AI clients. It is seva. No ads, no accounts, no analytics cookies or cross-site tracking, no commerce.

## What does the first release include?

- The Gurmukhi text of all 1,430 angs, with ang and line structure and author and raag metadata
- Romanized transliteration, generated locally by Open Granth
- English translation, imported and attributed, as a study aid
- The static website: reading, search, and verification
- A seven-tool MCP server that runs locally against the released files

## What is in scope?

Open Granth covers Sri Guru Granth Sahib Ji in its standard 1,430-ang form. It does not include bani outside the scope of this release, including Jaap Sahib, Tav-Prasad Savaiye, and Benti Chaupai. This is a project-scope boundary, not a judgment on their place or importance in Sikh tradition.

## Where does the text come from?

Gurmukhi text and metadata are derived from the [Shabad OS database](https://github.com/shabados/database), a maintained open-source database that can be used locally and reproducibly. Transliteration is generated locally by Open Granth. English is imported from the Shabad OS `DSSK` translation asset. Full attribution is in [NOTICE](NOTICE).

## What about the English translation?

The English layer comes from the `DSSK` translation asset in the Shabad OS database, attributed there to Dr. Sant S. Khalsa, publication date 2013-03. It is included as a study aid for readers who want English alongside the Gurmukhi. It is not Open Granth's own interpretation. Within Open Granth, the Gurmukhi is the source layer; the Roman and English layers are reading aids. Open Granth will not present AI-generated interpretation as authoritative Gurbani, and does not claim religious, scholarly, or interpretive authority.

If a rights holder believes a translation passage should be corrected, reattributed, or removed, see [TAKEDOWN.md](TAKEDOWN.md).

## What is the romanized line?

A reading aid. The Roman line is mechanically generated by Open Granth as an approximate companion to the Gurmukhi. It is not an authoritative pronunciation guide. Searches follow its spelling scheme: search for `vaahiguroo` rather than `waheguru`. The scheme and its limitations are documented in [docs/TRANSLITERATION.md](docs/TRANSLITERATION.md).

## What is the MCP server?

The Model Context Protocol server lets AI clients retrieve Gurbani from the released source files instead of generating it from memory. Responses carry ang and line citations, along with transliteration, English when present, and metadata.

The seven tools:

- `search_gurbani`: word-level search with stemming
- `lookup_ang`: full ang by page number
- `get_verse`: specific verse by ang and line
- `search_by_raag`, `search_by_author`: metadata queries
- `random_ang`: random-ang retrieval
- `verify_gurbani`: citation-first verification of a claimed quote

`verify_gurbani` is the trust layer: pass any text claimed to be from Sri Guru Granth Sahib Ji and receive a verified match with ang and line, a partial match, or a clear "not found." Here, "verified" means the text was found in the released files, with its location cited.

## Does Open Granth track visitors?

Open Granth uses privacy-preserving aggregate traffic measurements from Cloudflare to understand site usage. It does not use analytics cookies, profile individual visitors, or collect text entered into Search or Verify.

## Is Open Granth affiliated with Shabad OS or any institution?

No. Open Granth is an independent project by one person (Satnam Singh Narang). It is not affiliated with, endorsed by, or sponsored by Shabad OS or any Gurdwara, Jatha, Takht, or Sikh institution.

If you represent one of these organizations and have a concern, see [TAKEDOWN.md](TAKEDOWN.md) or email contact@opengranth.org.

## How do I run it locally?

```bash
git clone https://github.com/opengranth/open-granth.git
cd open-granth
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt

# Build and serve the site
python scripts/build_site.py --serve

# Run the MCP server
python mcp/server.py
```

The MCP server defaults to `./corpus/` as its source. Override with `--source-dir` or the `OPEN_GRANTH_SOURCE` environment variable.

## How do I report an error in a verse?

Open an issue on [GitHub](https://github.com/opengranth/open-granth) with the ang number, line number, and the specific issue. Transliteration errors, character encoding issues, and incorrect metadata are all welcome. Corpus files are generated by the import pipeline, so corrections land through that pipeline rather than through hand edits; an issue with the exact location is the fastest path to a fix.

## How do I contribute?

Pull requests are welcome for documentation, tests, tooling, and site improvements. For larger changes (new tools, new site features, new data layers), open an issue first so scope can be discussed. Corpus text itself is regenerated from source data, never hand-edited.

One thing to know up front: Open Granth is seva, not product. Contributions should be in that spirit. No commercial features. No analytics cookies or cross-site tracking. No accounts. No monetization of access to Gurbani.
